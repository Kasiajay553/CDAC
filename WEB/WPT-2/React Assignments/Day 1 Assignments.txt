Task 1
-------------
Write a React JS program to create a functional component named Student that displays the details of a student on a webpage.

The component should display the following information:

Student Name: CDAC

Course Name: React JS

College Name: ABC College

Academic Year: 2026

Requirements:

Create a separate file named Student.jsx.

Define a functional component named Student.

Use appropriate JSX elements such as <h2>, <p>, and <div> to display the student details.

Export the Student component using export default.

Task 2
-----------
Write a React JS program to create a functional component named InterestCalculator that calculates and displays the simple interest based on the given principal amount, rate of interest, and time period.

Use the following values:

Principal Amount (P): ₹10,000

Rate of Interest (R): 5% per annum

Time Period (T): 2 years

Formula:

Simple Interest = (P × R × T) / 100

Requirements:

Create a separate file named InterestCalculator.jsx.

Define a functional component named InterestCalculator.

Declare variables for the principal amount, rate of interest, and time period.

Calculate the simple interest using the given formula.

Display the principal amount, rate of interest, time period, and calculated simple interest using JSX elements.

Export the component using export default.

Import and use the InterestCalculator component inside App.jsx.

Run the application and verify the output in the browser.

Expected Output:

Simple Interest Calculator

Principal Amount: ₹10,000

Rate of Interest: 5%

Time Period: 2 years

Simple Interest: ₹1,000
